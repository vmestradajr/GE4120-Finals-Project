# Activity 5: AI Prompting

## Description
This activity explored how to create effective prompts and use artificial intelligence (AI) tools to generate useful and relevant outputs.

## What Have I Learned?
Through this activity, I learned how to create effective prompts and use AI tools to their full potential. One challenge I encountered was expressing my ideas clearly and putting into words the specific output I wanted the AI tool to generate. This experience helped me understand the importance of providing clear and specific instructions when using AI tools. In the future, I can apply this skill to make tasks easier, improve my productivity, and use AI as a helpful tool for learning, brainstorming, and completing different activities.
