# Activity 1: Poster Design

## Description
This activity focused on creating and organizing a clear and visually appealing poster that effectively communicates its intended message.

## What Have I Learned?
Through this activity, I learned how to create and organize a clear and visually appealing poster. One challenge I faced was choosing and combining colors that complement each other while still conveying the main message of the poster. I realized that selecting the right color combinations is important in creating an effective design. I can improve this skill by practicing more, experimenting with different color combinations, and continuously challenging myself to become better at designing.
