# Activity 6: Website Creation

## Description
This activity focused on creating a website and organizing ideas and content into a presentable and well-structured layout.

## What Have I Learned?
Through this activity, I learned how to create a website and organize my ideas and content into a presentable and well-structured layout. One challenge I encountered was deciding what content to include and how to arrange everything properly on my website. This experience helped me understand the importance of proper content organization and website presentation. In the future, I can use this skill to create personal or academic websites, showcase my work, and present information in a more organized and accessible way.
